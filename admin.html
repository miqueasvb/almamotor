Acceso al panel

Este panel publica cambios directamente en tu repositorio de GitHub. Necesitás un token de acceso personal con permiso de lectura/escritura sobre ese repositorio. Ver instrucciones abajo del formulario.
Es solo un filtro de conveniencia para que no cualquiera abra el formulario. La seguridad real la da el token de GitHub.
Creá uno en GitHub → Settings → Developer settings → Fine-grained tokens → "Generate new token". Elegí "Only select repositories" y seleccioná este repo. En permisos, dale Contents: Read and write (nada más). Ponele una fecha de expiración corta (ej. 90 días) y renovalo cuando venza.
